# 🛒 Souq E-Commerce RESTful API

A robust backend RESTful API built with **Node.js**, **Express.js**, and **MongoDB** for managing an E-Commerce platform. It features JWT-based authentication, authorization middleware, product lifecycle, dynamic shopping cart management, and automated order creation.

---

## 🛠 Tech Stack

* **Runtime Environment:** Node.js
* **Framework:** Express.js
* **Database:** MongoDB & Mongoose
* **Authentication:** JSON Web Tokens (JWT) & bcryptjs
* **Testing Tool:** Postman

---
